## 用户确定的规则

- Token只估算和记录实际用量，不作为应用层硬停止条件。
- 普通ReAct决策最多5轮。选择Skill、补查Schema／口径、查询、计算、读结果、澄清或决定交付等，都按实际发起的正常决策调用计轮。
- 每条逻辑SQL**总共最多生成2次**，即首次生成加一次重写。SQL技术修复不占上述5轮，只能修正原目标、原范围和原依赖下的SQL／契约，不能选择新调查方向或追加查询。
- Flash入口理解、草稿和独立最终审核不占5轮，但仍计模型调用和用量。5轮不是全部模型调用最多5次，也不是人民币金额上限。
- 工具20次、非SQL动作额外修复2次、主动300秒／调查240秒、前端360秒及权限、快照、只读校验保留。
